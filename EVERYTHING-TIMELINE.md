## Rules for keeping this roadmap manageable

- **One active focus:** keep only one exercise phase or project as the immediate task.
- **Next few steps only:** use this file for direction, and the full roadmaps for detailed instructions.
- **Finish before expanding:** prioritise complete, working projects over accumulating unfinished ones.
- **Learn, then apply:** use exercises to understand a skill, projects to apply it, and stretch tasks to improve it.
- **Keep the portfolio current:** when a project is finished, update its status, completion date, README and GitHub profile as appropriate.
- **Keep optional work optional:** do not let the Stage 5D backlog distract from the robotics specialism.
