# Programming Roadmap

This repository is the control centre for my programming learning
journey and portfolio development. It keeps my long-term direction,
project order, exercise roadmap, working preferences, and stretch-task
tracking in one place.

## Repository structure

``` text
programming-roadmap/
├── README.md
├── CLAUDE.md
├── EVERYTHING-TIMELINE.md
├── roadmaps/
│   ├── project-timeline.md
│   └── exercises-roadmap-and-instructions.md
├── tracking/
│   └── stretch-tasks.md
└── templates/
    ├── project-template.md
    └── exercise-phase-template.md
```

## What each file is for

-   **`CLAUDE.md`** --- the master instructions for how Claude should
    teach, guide, review code, and help manage projects.
-   **`EVERYTHING-TIMELINE.md`** --- the quick overview of the overall
    learning and project sequence.
-   **`roadmaps/project-timeline.md`** --- the detailed portfolio
    project plan and dependencies.
-   **`roadmaps/exercises-roadmap-and-instructions.md`** --- the
    exercise phases and their learning structure.
-   **`tracking/stretch-tasks.md`** --- optional improvements and
    stretch-task progress.
-   **`templates/`** --- reusable starting points for future projects
    and exercise phases.

## Keeping the repository current

After finishing a project or exercise phase:

1.  Update its status and completion date in the relevant roadmap.
2.  Update `EVERYTHING-TIMELINE.md` if the current focus or next step
    has changed.
3.  Update stretch-task progress where relevant.
4.  Commit the changes with a short message beginning with a verb, for
    example `Update project 14 status`.

Keep this repository separate from individual portfolio project
repositories. It tracks the learning journey; each software project
should retain its own repository.

## Privacy and safety

Keep this repository private initially if it contains personal learning
notes or plans. It can be made public later if desired.

Never commit passwords, access tokens, private keys, or real
personal/medical data. Use synthetic sample data in portfolio projects.
